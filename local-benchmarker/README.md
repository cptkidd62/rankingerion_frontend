# LOCAL BENCHMARKER

## About
Lacal Benchmarker TLS server for local testing end development purposes. 

## Installation and usage
To run locally run `generate-certs.sh` (if not performed previously and no certs are present in `certs/` folder) and then run `run-local-benchmarker.sh`. This will start a local Benchmarker TLS server at `0.0.0.0:5555`.
