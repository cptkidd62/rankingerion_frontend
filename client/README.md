# RANKINGERION CLIENT

## About
Vue based frontend client for Rankingerion system.

## Installation and usage
To run locally run `run-client.sh` in this folder. After that you can access it on port 5173.
Unmodified version requires server on port 3000 to be running.
Otherwise, when not using nginx, a correst address of server should be set in `client/src/api/url.ts` preceeding `/api`.
